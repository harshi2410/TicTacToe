Made tic tac toe game using min max algorithm
download the file and then run python concept.py in terminal , u can play the game with ai
Tech stack: Python + Minimax Algorithm + Tkinter GUI
Features
- Play against an AI opponent.
- AI uses Minimax to choose the best move.
- Simple 3×3 clickable game board.
- Displays win, loss, or draw.
- Tracks your wins, AI wins, and draws.
- Restart button to play again.
